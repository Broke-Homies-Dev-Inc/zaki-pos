# Bill Output Directory

This directory stores PDF bills generated by the POS system when **Print Preview is disabled** in Settings.

## How It Works

1. Navigate to **Settings → Print Settings**
2. Toggle "Enable Print Preview" to **OFF**
3. Generate bills from the Billing page
4. PDF files will be saved here automatically

## File Naming Convention

Bills are saved with the following format:
```
Bill-[OrderNumber]-[Timestamp].pdf
```

Example: `Bill-ORD-001-2025-10-18T08-30-15.pdf`

## Note

- PDF files in this directory are excluded from git (see .gitignore)
- Clean up old bills periodically to save disk space
- Each bill includes order details, customer info, and loyalty points (if applicable)
